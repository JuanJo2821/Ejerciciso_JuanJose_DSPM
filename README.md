# Challenge 02 - PWA

**Link de despliegue:** https://lucent-valkyrie-e39e0d.netlify.app/


### Android
1. Abre el link de la app en Chrome desde tu celular
2. Toca el menú de tres puntos en la esquina superior derecha
3. Selecciona **"Instalar app"** o **"Añadir a pantalla de inicio"**
4. Confirma la instalación

### iPhone
1. Abre el link de la app en Safari desde tu celular
2. Toca el botón de los 3 puntos de abajo a la derecha
2. Toca el botón de compartir
3. Desplázate hacia abajo y selecciona **"Agregar al inicio"**.
4. Confirma el nombre y toca **"Añadir"**.
